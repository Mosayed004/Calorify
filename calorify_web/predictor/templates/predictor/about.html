Project Explanation

About Calorify

Calorify is a multimodal food recognition and calorie estimation demo. It combines an image classification model with a text-based calorie estimation model to produce an interpretable food prediction result.

Image Branch EfficientNetB0

The uploaded food image is processed by a transfer learning image model. The model predicts the most likely food class and returns top-3 class probabilities.

Text Branch TF-IDF + Ridge

The meal description is processed by a trained text regression model. This branch estimates calories based on ingredients and food-related words.

How the Pipeline Works

Step Component Purpose
1 Image Upload The user uploads a food image through the Django web interface.
2 Image Model EfficientNetB0 predicts the food class, confidence score, and top-3 predictions.
3 Text Input The user describes ingredients, portion, sauce, and preparation style.
4 Calorie Model TF-IDF + Ridge estimates calories from the food description.
5 Final Output The system displays predicted food, confidence, calories, range, and warnings.

Important Limitations

Estimated, Not Exact No exact calorie claim

The system estimates calories from the text description. It does not measure exact ingredient weight, plate size, or real portion mass from the image.

No Fixed Mapping Not burger = fixed kcal

Calorify does not use a fixed food-class-to-calorie lookup. The estimated calories come from the trained text calorie model.

Image-Text Consistency Mismatch warning

If the image prediction and text description appear inconsistent, the system displays a warning to help the user review the input.

Why This Design Was Used

Directly predicting exact calories from an image alone is unreliable because the image does not provide accurate food weight or hidden ingredient quantities. Calorify therefore separates the task into two branches: visual food recognition and text-based calorie estimation. This makes the system more explainable and easier to defend during evaluation.
